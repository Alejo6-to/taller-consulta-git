Git es un sistema de control de versiones que nos permite registrar los cambios que realizamos en un proyecto, mantener un historial, recuperar versiones anteriores y trabajar con ramas (branches). GitHub es una plataforma en línea que permite alojar repositorios, compartir proyectos y trabajar en equipo. Git y GitHub no son lo mismo: Git controla las versiones de manera local, mientras que GitHub permite almacenar y compartir esos proyectos en la nube. Para trabajar utilizamos comandos como git clone, que permite clonar un repositorio; git status, que muestra el estado de los archivos; git add ., que agrega los archivos nuevos y modificados a la zona de preparación (Staging Area); git commit -m, que registra los cambios en el historial local; git push, que sube los cambios a GitHub; y git pull, que trae los cambios del repositorio remoto. También estudiamos las ramas (branches), que permiten trabajar en diferentes funcionalidades sin modificar directamente la rama principal, facilitando el trabajo individual y en equipo. Además, conocimos GitFlow, una metodología que organiza el trabajo mediante ramas con responsabilidades específicas. Por otro lado, estudiamos React Router, una biblioteca que permite manejar la navegación entre diferentes páginas o vistas de una aplicación React sin tener que recargar todo el sitio. Conocimos tres modos: Declarative Mode, que permite definir las rutas y navegar entre pantallas; Data Mode, que permite gestionar la carga y el envío de datos mediante herramientas como loader y action, utilizando useLoaderData para acceder a los datos cargados; y Framework Mode, que ofrece una estructura más completa para desarrollar aplicaciones, integrando herramientas de rutas, carga de datos y otras funcionalidades.
